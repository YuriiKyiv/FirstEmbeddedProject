# Модуль 2, урок 28 — Світлофор

Домашнє завдання: автомат станів із послідовністю сигналів з умови.
Збірка через PlatformIO, платформа `espressif32@7.1.3`, Arduino-ESP32 **2.0.17**.
Профіль плати: `esp32-s3-devkitc-1` (8 MB Flash, без PSRAM).

## Архітектура

- **Апаратний таймер 0 — `stateTimer`**: одноразовий, задає тривалість поточного стану.
- **Апаратний таймер 1 — `blinkTimer`**: періодичний, кожні 500 мс змінює фазу миготіння.
  Працює лише у станах зеленого та жовтого миготіння.
- ISR обох таймерів і кнопки лише встановлюють свої прапорці `volatile bool`.
- `loop()` зчитує та скидає прапорці, перевіряє кнопку і передає події в автомат.
  У програмі немає `delay()` чи очікування завершення стану.
- Антидребезг кнопки — неблокуючий, через `millis()`: новий рівень має бути стабільним 200 мс.

Таймери використовують дільник 80: 80 МГц / 80 = 1 МГц, отже один тік — 1 мкс.
Мілісекунди тривалості перетворюються на тіки множенням на 1000.
`timerAlarmWrite(..., false)` задає одноразову подію, `true` — автоматичне повторення.
Код використовує API Arduino-ESP32 **2.x**; у 3.x API таймерів змінено
([офіційна інструкція міграції](https://docs.espressif.com/projects/arduino-esp32/en/latest/migration_guides/2.x_to_3.0.html)).

`volatile` забезпечує звернення до спільного прапорця, але не робить послідовність
«прочитати й скинути» неподільною. Тому `takeEvents()` коротко вимикає переривання.
Це розраховано на реєстрацію всіх ISR у `setup()` на тому самому ядрі, де працює `loop()`.
Прапорці не накопичують кількість спрацювань: обробка `loop()` має бути коротшою за 500 мс.

Пріоритет подій: **підтверджене натискання → завершення стану → крок миготіння**.
Після переходу таймери переозброюються, фаза починається з увімкненого LED,
а таймерні події попереднього стану відкидаються.

## Послідовність

| Стан | Тривалість | Увімкнені світлодіоди |
| --- | --- | --- |
| Зелений | 10 с | Зелений |
| Зелений миготливий | 3 с | Зелений: 500 мс увімкнений / 500 мс вимкнений |
| Жовтий | 3 с | Жовтий |
| Червоний | 10 с | Червоний |
| Червоний + жовтий | 2 с | Червоний і жовтий одночасно |
| Зелений | Початок нового циклу | Зелений |

Повний цикл — 28 секунд. Тривалості взято із заготовки заняття; це навчальні
налаштування, а не нормативні тривалості сигналів.

Кнопка в будь-якому стані вмикає **жовтий миготливий**. Таймер стану тоді зупинений,
а таймер миготіння працює до наступного натискання. Наступне натискання відновлює
цикл через **червоний → червоний + жовтий → зелений**.
Утримання кнопки не повторює подію; для нового натискання потрібно відпустити
кнопку щонайменше на 200 мс. Беззнакове віднімання часу враховує переповнення `millis()`.

## Підключення

| Компонент | Пін ESP32-S3 | Підключення |
| --- | --- | --- |
| Зелений LED | GPIO5 | GPIO → резистор 330 Ом → анод; катод → GND |
| Жовтий LED | GPIO6 | GPIO → резистор 330 Ом → анод; катод → GND |
| Червоний LED | GPIO7 | GPIO → резистор 330 Ом → анод; катод → GND |
| Кнопка | GPIO4 | Між GPIO4 і GND, внутрішня підтяжка `INPUT_PULLUP` |

Кожен LED має окремий резистор. `HIGH` вмикає LED, `LOW` вимикає.
Кнопка натиснута при `LOW`; переривання `CHANGE` фіксує натискання та відпускання.
Піни збережено із заготовки; змінити їх можна в `main/main.cpp`.

## Збирання та запуск

У терміналі PlatformIO або з установленим PlatformIO CLI, з кореня репозиторію:

```sh
cd module2
pio run -e esp32-s3
pio run -e esp32-s3 -t upload --upload-port /dev/cu.YOUR_BOARD
pio device monitor --port /dev/cu.YOUR_BOARD --baud 115200
```

Замініть порт на порт своєї плати. На цьому комп'ютері CLI встановлений за шляхом
`~/.platformio/penv/bin/pio`; його можна використати замість `pio`.
У VS Code відкрийте папку `module2` як проєкт PlatformIO. Точка входу — `setup()`/`loop()`
у `main/main.cpp`; попередню конфігурацію CMake для ESP-IDF замінено на `platformio.ini`.
Поточне джерело для прошивання — `.pio/build/esp32-s3/firmware.bin`.

Автомат і визначення подій розміщено в `main/traffic_light.c` та `main/traffic_light.h`.
У Serial друкуються назви станів: `GREEN`, `GREEN_BLINK`, `YELLOW`, `RED`,
`RED_YELLOW`, `YELLOW_BLINK`.

## Перевірка та результат виконання

Прошивка успішно зібрана для ESP32-S3:
[журнал Arduino-збірки](results/arduino-build.txt).
На фізичній платі прошивку ще не перевірено.

Для перевірки на комп'ютері потрібні C/C++ компілятори:

```sh
sh tests/run.sh
```

Перевіряються автомат станів і справжні `setup()`/`loop()` із модельованими
Arduino API, GPIO та апаратними таймерами: два цикли, одноразові/періодичні спрацювання,
миготіння, антидребезг, утримання кнопки, переповнення `millis()`, одночасні події,
зчитування прапорців, помилка створення таймерів і відсутність конфліктних сигналів.

Збережений результат: [results/host-simulation.txt](results/host-simulation.txt).
Це **симуляція, не запис із фізичної плати**. У демонстрації підтверджені
натискання відбуваються на 29-й та 31-й секундах.
Для здачі додайте відео/фото повного циклу й перемикання кнопкою та журнал
Serial з плати в `results/`.
